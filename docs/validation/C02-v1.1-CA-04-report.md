## Principe

HAT #4 a isolé une classe unique : la validation stricte de T est appliquée **après** qu'un
wrapper générique a déjà perdu le type brut (`True → Pydantic Knowable[int] → 1`). CA-04
contrôle le type d'entrée **avant** toute conversion Pydantic destructive. BC-14 n'est pas
affaibli. Les comptages, l'ACK de licence et les décisions DATA conservent une sémantique
de type stricte.

## Audit `Knowable[T]` (spécialités réellement utilisées par C02)

| T | Voies JSON nécessaires | Coercition destructive via wrapper ? | Traitement |
|---|------------------------|--------------------------------------|------------|
| `int` | nombre JSON → `int` | oui (`true`, `1.0`, `"1"`, `bool`) | type exact avant conversion |
| `bool` | `true`/`false` JSON → `bool` | oui (`1`, `"yes"`, `"true"`) | type exact avant conversion |
| `str` | identité | pas plus permissif qu'un champ `str` C02 | inchangé |
| `date` | `str` ISO | non — coercition normative | conservée |
| `AdjustmentMethod` / `AdjustmentReferenceDate` | `str` → enum | non — coercition normative | conservée |
| `tuple[str, …]` | `list` → tuple | non | conservée |
| `SessionRange` | objet → modèle | non | conservée |
| `Decimal` / `datetime` | — | non utilisés dans `Knowable` | rien à faire |

Règle retenue : `Knowable[T]` ne rend pas plus permissive la politique de T. Aucun
`strict=True` générique (casserait str→date / str→enum). Aucune autre coercition
sémantiquement destructive trouvée hors `int` / `bool`.

## Audit borné wrapper / conteneur

Classe cherchée : T valide isolément, plus permissif derrière un wrapper C02.

| Forme | `int` / `bool` scientifiques | Résultat |
|-------|------------------------------|----------|
| T isolé (`Field(strict=True)`) | déjà strict (CA-03) | inchangé |

| `FrozenMap[..., Knowable[T]]` | héritait du wrapper | corrigé |
| modèle imbriqué (`ObservationCounts`, `LicenseRef`, artefact, snapshot, I01) | héritait du wrapper | corrigé |

`request_parameters` reste un objet QCJ-1 de **scalaires** (hors M2). `FrozenMapping[JsonScalar]`
accepte un booléen JSON comme scalaire, ce qui n'est pas un entier scientifique encapsulé.

## Hypothesis (`dev` uniquement)

- `type(x) is not bool` ⇒ `Knowable[bool](x)` rejeté ;
