## Anomalie BLOQUANTE

### HAT4-B1 — BC-14 contourné par `Knowable[int]` / `Knowable[bool]`

**Propriété revendiquée (BC-14, décision CA-03 M9) :** les booléens et entiers scientifiques
sont stricts — plus de `"yes"`→`True`, `True`→`1`, `1.0`→`1` — là où la coercition change le
sens (gates, **comptages**, **ACK booléen**).

**Isolation :** la propriété tient sur les champs `Field(strict=True)` (`survivorship_bias_acknowledged="yes"`,
`raw_observations=True`, `byte_size=1.0`, `step_index=True`).

**Composition :** dès que la valeur passe par `Knowable[int]` ou `Knowable[bool]`, Pydantic coerce
**avant** les gardes `isinstance(..., bool)` de `ObservationCounts` / `TransformationRecord`
(donc ces gardes sont mortes). Reproduit par le rédacteur sur constructeur, `model_validate` et
`model_validate_json` :

| Entrée | Résultat observé |
|--------|------------------|
| `Knowable[int].known(True)` | `value == 1` (`int`) |
| `Knowable[int].known(1.0)` | `value == 1` (`int`) |
| `Knowable[int].model_validate_json('{"status":"KNOWN","value":true}')` | `value == 1` |
| `Knowable[bool].known("yes")` / `(1)` / `(1.0)` / `(0)` | `True` / `True` / `True` / `False` |
| `ObservationCounts(..., expected_sessions=known(True), missing_sessions=known(False))` | expected=1, missing=0 ; INV-15 passe |
| `TransformationRecord` counts `known(True)`, `known(1.0)`, `known(False)` | 1, 1, 0 |
| `LicenseRef.raw_retention_permitted=known("yes")` | `True` |

**I01 P-06 :** un artefact dont la rétention est `known("yes")` ou `known(1)` a la même `ref()`
qu'un `known(True)` ; `verify_artifacts` réussit ; le profil est `conforms=True` et
`data_pass_eligible=True`. `known(0)` devient `False` et échoue INV-09 (mismatch de licence),
pas le typage.

Cas d'isolation trompeur : `ObservationCounts(..., known(True), known(True))` peut encore
être rejeté par INV-15 (1+1≠1) **après** coercition, ce qui masque l'absence de contrôle de type.

Ce n'est pas une limitation déclarée. BC-14 est donc faux dès qu'un entier ou un booléen
scientifique est encapsulé dans `Knowable`.
